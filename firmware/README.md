# MESS firmware

ESP-IDF v6.1 firmware for ESP32, providing I2C, ESP-NOW, and laptop Wi-Fi/browser terminals.

See the [project README](../README.md) for build and flash setup, and [CONSOLES.md](CONSOLES.md) for commands and hardware verification.

The active entry point is `main/app_main.c`. The CMake project name remains `hello_world`, so the generated firmware is named `hello_world.bin`.
